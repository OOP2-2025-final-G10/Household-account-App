# アプリ名: Household-Account-App

概要:
このアプリケーションでは、ユーザー、カテゴリを記録することができ、それを用いて家計簿記録を行うことがdきます。

また、記録した収支情報を利用し、支出・収入ごとのカテゴリーの円グラフとユーザーごとの収入と収支を棒グラフで一目で把握することが可能です。


## アピールポイント
ユーザー一覧ページからユーザーを確認することができ、カテゴリーページから現在のカテゴリ一覧を確認でき、また、新規追加も可能。
家計簿記録ページからは、ユーザー、カテゴリ、値段を入力することで、家計簿記録をつけることができる。
家計簿記録に基づいてトップページでは、ユーザーごとの支出・収入の内訳、支出・収入がどのような比率になっているかを確認可能。
